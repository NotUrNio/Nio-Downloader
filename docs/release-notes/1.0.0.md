# Nio Downloader 1.0.0

Nio Downloader 1.0.0 is the first stable release of the full-featured, open-source download manager designed for high throughput, reliability, and modern desktop workflows.

## Key Capabilities

### High-Throughput Download Engine
- Multi-connection downloading powered by aria2 with automatic split-connection acceleration across HTTP/HTTPS, FTP, BitTorrent, and Metalink protocols.
- Intelligent task queueing, bandwidth limits, dynamic segment allocation, and real-time speed monitoring.
- High-efficiency disk cache and optimized socket handling designed for high-speed connections.

### Native Browser Integration
- Companion browser extension support for Chromium (Chrome, Edge, Brave, Vivaldi), Firefox, and Safari.
- End-to-end encrypted local bridge communication pairing browser triggers directly with the desktop engine.
- Automatic download takeover for configured file formats, URL schemes (`magnet:`, `thunder:`, `flashget:`), and context-menu actions.

### Plugin and Extension System
- Extensible runtime supporting custom site resolvers, post-processing hooks, and protocol handlers.
- Safe sandboxing with granular capability declarations and origin permission gating.

### Cross-Platform Desktop Experience
- Modern native desktop interfaces across macOS (Apple Silicon and Intel), Windows (x64), and Linux (AppImage, Flatpak, deb, rpm, pacman).
- System tray integration, dark and light theme adaptability, configurable autostart, and native desktop notifications.
- Headless server mode deployable via Docker containers for remote orchestration and automated workflows.

## Installation and macOS Gatekeeper

### macOS Installation
1. Download `Nio-Downloader-1.0.0-arm64.dmg` (for Apple Silicon) or `.zip`.
2. Open the disk image and drag **Nio Downloader** into your Applications folder.
3. Because community builds are distributed ad-hoc signed without an Apple Developer ID signature, macOS Gatekeeper may prompt on first launch. To open:
   - Right-click (or Control-click) **Nio Downloader.app** in Applications and choose **Open**, then confirm **Open** in the dialog.
   - Alternatively, remove the quarantine attribute via Terminal:
     ```bash
     xattr -d com.apple.quarantine "/Applications/Nio Downloader.app"
     ```

## Verification and Checksums

Verify the authenticity and integrity of downloaded files using `SHA256SUMS.txt`:

```bash
shasum -a 256 -c SHA256SUMS.txt
```

## Known Limitations

- **Platform Builds**: The initial local release build provides the native macOS Apple Silicon (`arm64`) DMG and ZIP packages. macOS Intel (`x64`), Windows (`.exe`), and Linux (`.AppImage`, `.deb`, `.rpm`, `.pacman`, Flatpak, Snap) are built and validated via GitHub Actions CI workflows.
- **Auto-Update Behavior**: Unsigned and ad-hoc signed macOS builds display a direct download link when an update is available instead of executing silent in-place replacement.
- **Open-Source Engine**: The embedded aria2 download engine is licensed under the GNU General Public License (GPLv2+). In compliance with the GPL source code offer, the complete matching source code archive `aria2-1.37.0-motrix.16-source.tar.gz` is attached directly to this release.
