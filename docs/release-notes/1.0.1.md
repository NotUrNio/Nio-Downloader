# Nio Downloader 1.0.1

Nio Downloader 1.0.1 brings core download engine updates, real-time inspector analytics, and enhanced profile resilience, while preserving Nio Downloader's design language, security boundaries, and neutral naming contracts.

## Key Capabilities

### Download Engine Update
- Bundled aria2 engine updated to build 1.37.0.19 across all supported desktop platforms.
- Added Windows ARM64 build targets (`win32-arm64`), expanding native Windows architecture support alongside `x64` (marked unverified until tested on native hardware).
- Neutral binary packaging contracts: distributed as `aria2-engine-1.37.0.19-<os>-<arch>.<ext>` and `aria2-engine-source-1.37.0.19.tar.gz`.

### Inspector and Transfer Analytics
- Real-time activity charts and lifetime transfer cards in the task inspector, tracking active speeds and total transferred bytes per task.
- Interactive re-download confirmation dialog when attempting to download over an existing file.
- Speed limit unit selector supporting KiB/s, MiB/s, and GiB/s across global and per-task bandwidth configurations.

### Settings and Network Management
- Independent proxy scope toggle for plugin installation and updates (`scopes.plugins`).
- Improved STUN server list validation and engine DNS resolution mode management.
- CLI tool status section in integration settings with native command copy support.

### Profile Migrations and Resilience
- Safe migrations v8 and v9 for the SQLite profile database, featuring automatic backup snapshots prior to migration execution.
- Added UI recovery boundary and exit snapshot handling for graceful session persistence.
